Steps to run program: 

Check Java is installed

Open CMD (Command Prompt)

Type: java -version

If java version show, it means java installed and working

Go to correct drive

If file is in D: drive, type: D:

Now CMD show D:\>

Go to folder where file saved

Type: cd "D:\Computer Programming\java_codes"

Quotes needed because folder name have space

Check file is in folder

Type: dir

You should see hello.java file

Compile java program

Type: javac hello.java

If no error, it make hello.class file

This step convert java code into bytecode

Run program

Type: java hello

CMD show: Hello, World!
